# Slipstream static certificate distrust list.
#
# Applied to every certificate chain the viewer's own HTTPS stack verifies (alongside
# Chrome's CRLSet, which is fetched at runtime), so a known-bad CA is refused even with
# no CRLSet at all. This file is data: add entries here, no code change needed.
#
# Format, one entry per line; '#' starts a comment:
#   <SHA-256 of the certificate's DER SubjectPublicKeyInfo, 64 hex digits>
#       blocks that key wherever it appears in a chain (all cross-signs of a CA included)
#   serial <issuer SPKI SHA-256, 64 hex> <serial number, hex>
#       blocks the one certificate with that serial issued by that key
#
# SPKI hash of a certificate:
#   openssl x509 -in cert.pem -noout -pubkey | openssl pkey -pubin -outform DER \
#     | openssl dgst -sha256
# A malformed line makes the viewer ignore the whole file (and log why), so check with
#   scripts/revocation/test_revocation.sh
#
# ---------------------------------------------------------------------------------------
