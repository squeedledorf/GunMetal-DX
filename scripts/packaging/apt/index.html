Slipstream apt repository

Signed apt repository for the Slipstream Second Life viewer. Ubuntu 24.04+, Debian 13+, Linux Mint 22+ (amd64). Slipstream is not provided or supported by Linden Lab.

Install

Pick one suite: stable (releases only) or beta (betas and releases, always the newest). For beta, use slipstream-beta.sources below.

sudo wget -qO @KEYRING_FILE@ @APT_URL@/slipstream-archive-keyring.asc
sudo wget -qO /etc/apt/sources.list.d/slipstream.sources @APT_URL@/slipstream.sources
sudo apt update && sudo apt install slipstream-viewer slipstream-archive-keyring

Updates then arrive with sudo apt upgrade. The slipstream-archive-keyring package keeps the signing key current.

Verify the key

gpg --show-keys @KEYRING_FILE@

The primary key fingerprint must match the one published on slipstreamviewer.org/wiki/verify.

Remove

sudo apt remove slipstream-viewer slipstream-archive-keyring
sudo rm /etc/apt/sources.list.d/slipstream.sources @KEYRING_FILE@
