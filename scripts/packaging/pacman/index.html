Slipstream pacman repository

Signed pacman repositories for the Slipstream viewer (slipstream-bin, x86_64), so pacman -Syu keeps it current. Pick one of the two repositories.

1. Trust the signing key

curl -fsSLO @PACMAN_URL@/slipstream.asc
gpg --show-keys --with-fingerprint slipstream.asc     # must show @FPR@
sudo pacman-key --add slipstream.asc
sudo pacman-key --lsign-key @FPR@

2. Add the repository

Stable releases:

curl -fsS @PACMAN_URL@/slipstream.conf | sudo tee -a /etc/pacman.conf

Betas and releases (a beta user always has the newest build):

curl -fsS @PACMAN_URL@/slipstream-beta.conf | sudo tee -a /etc/pacman.conf

3. Install

sudo pacman -Syu slipstream-bin

Older package files stay in the repository for a while: sudo pacman -U @PACMAN_URL@/slipstream/os/x86_64/<file>. More: slipstreamviewer.org/wiki/install.
